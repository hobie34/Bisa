# EmailFlowBackend

This project is the backend for EmailFlow, an application designed to streamline email management and workflow.

## Overview

The EmailFlowBackend provides the core API and services for the EmailFlow application. It handles user authentication, email processing, workflow automation, and data storage.

## Features

*   User Authentication and Authorization
*   Email Fetching and Parsing
*   Workflow Definition and Execution
*   Notification System
*   API for Frontend Communication

## Technology Stack

*   **Language:** Python
*   **Framework:** Django
*   **Database:** PostgreSQL

## Getting Started

### Prerequisites

*   Python 3.8+
*   Poetry
*   Docker

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    ```
2.  Navigate to the project directory:
    ```bash
    cd EmailFlowBackend
    ```
3.  Install dependencies:
    ```bash
    poetry install
    ```

### Running the Application

```bash
poetry run python manage.py runserver
```
